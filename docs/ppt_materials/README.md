## 二、项目一句话介绍（各处都能用）

**AI 旅游智能体助手**：用户用一句自然语言提出旅行需求（如「从福州自驾到杭州 6 天 5 夜」），系统由**总控智能体调度 7 个子智能体**，调用高德地图与聚合数据的**真实 API**，最终在聊天界面输出含路线分段、沿途景点、天气、住宿、餐饮与预算的**逐日行程**。

## 三、可直接复用的硬数据（汇报时最有说服力）

| 项目 | 数据 |
|---|---|
| 技术栈 | FastAPI + openai-agents SDK + 通义千问（DashScope）+ Pydantic + 原生 HTML/CSS/JS |
| 智能体数量 | 1 个总控 + 6 个业务子智能体（路线/天气/酒店/交通/美食/预算）+ 1 个行程编排 |
| 分层 | Agent_com → skill → mcp_tools → 外部 API（4 层） |
| 外部数据源 | 高德开放平台（地理编码/驾车路径/POI/天气）+ 聚合数据（火车票/航班） |
| 开发阶段 | P1 ~ P9 共 9 个阶段，每阶段 1 次提交 + 1 份验收证据 |
| 真实路线 | 福州 → 杭州 611 km / 7.3 h / 过路费 237 元 |
| 真实火车 | 杭州 → 福州 G1621，07:09-11:22，二等座 ¥281 |
| 真实航班 | 杭州 → 北京 MU5131，07:20-09:45 直飞，¥490 |
| 真实餐厅 | 杭州杭帮菜人均 100 元内：赵府私厨 ¥66、四灶儿 ¥79、新周记 ¥81 |
